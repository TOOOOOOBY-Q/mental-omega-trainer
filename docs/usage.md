# 使用说明

## 环境要求

- 游戏：心灵终结 Mental Omega 3.3.6（Yuri's Revenge 1.001 + Ares）
- 系统：Windows 10 / 11
- 运行时：.NET Framework 4.x（Windows 内置）

## 快速开始

1. 启动游戏并进入一局单机游戏（战役或遭遇战）。
2. 双击修改器，同意 UAC 管理员授权。
3. 状态区显示“已连接 · 游戏中”后即可使用功能。

## 功能与快捷键

| 功能 | 快捷键 | 类型 |
| --- | --- | --- |
| 资金 | F5 | 一次性：设为界面填写的数值 |
| 无限电力 | F6 | 开关：锁定电力输出 / 消耗 |
| 一键全图 | F7 | 一次性：揭开当前玩家全部视野 |
| 快速建造 | F9 | 开关：锁定工厂建造速度 |
| 无限超级武器 | F10 | 开关：保持超武充能完成 |
| 立即胜利 | F11 | 一次性：写入胜利标记 |

界面上“窗口置顶”开关可将修改器保持在游戏窗口上方。

## 行为说明

- 游戏进程启动后修改器会自动连接，无需手动选择进程。
- 开启快速建造后再进入新的一局，会自动刷新该局的现场值。
- 关闭快速建造或退出修改器时，会自动恢复被修改的建造数值并注销热键。
- 一键全图为一次性操作，每局需要重新按一次。

## 故障排查

点击界面中的“复制诊断”，将内容连同问题一起提交 Issue。诊断信息包含版本、系统、进程状态和运行记录，不包含任何个人凭据。

常见问题：

- “未检测到 gamemd.exe”：游戏未启动，或进程名被第三方启动器重命名。
- “请先进入一局游戏”：已连接游戏进程，但尚未进入对局。
- 功能不生效：确认游戏为 3.3.6 版本；其他版本布局不同，修改器会拒绝写入。
- 快捷键无响应：使用界面按钮代替；两者逻辑完全相同。

## 安全提示

- 仅用于单机游戏，不要用于联机对战。
- 发布版本为自签名，可能出现 SmartScreen 提示，属预期现象。
- 仅从本仓库 Release 下载并核对 SHA-256。
