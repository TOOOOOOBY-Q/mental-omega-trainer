# 使用说明

## 环境要求

- 游戏：心灵终结 Mental Omega 3.3.6（Yuri's Revenge 1.001 + Ares）
- 系统：Windows 10 / 11
- 运行时：.NET Framework 4.x（Windows 内置）

## 快速开始

1. 启动游戏并进入一局单机游戏（战役或遭遇战）。
2. 双击修改器，同意 UAC 管理员授权。
3. 状态区显示“已连接 · 游戏中”后即可使用功能。

## 功能与快捷键

| 功能 | 快捷键 | 类型 |
| --- | --- | --- |
| 资金 | F5 | 一次性：设为界面填写的数值 |
| 无限电力 | F6 | 开关：锁定电力输出 / 消耗 |
| 一键全图 | F7 | 一次性：揭开当前玩家全部视野 |
| 快速建造 | F9 | 开关：建筑和单位近乎立即完成（正常扣款） |
| 无限超级武器 | F10 | 开关：保持超武充能完成 |
| 立即胜利 | F11 | 一次性：写入胜利标记 |

界面上“窗口置顶”开关可将修改器保持在游戏窗口上方。

资金区域先输入目标金额，再点击“应用资金”或按 F5。三项持续功能显示“已开启 / 已关闭”，底部统计当前开启数量。Tab 键按界面顺序移动焦点，空格切换选中的开关，按钮可用空格或 Enter 执行。

未进入对局时，状态区会提示等待，操作暂不可用；离开对局后，已开启的功能仍可关闭。连接失败会直接显示原因并记录诊断。界面固定为 820×620 像素，字体也固定尺寸；屏幕高度不足时可在窗口内纵向滚动。

## 行为说明

- 游戏进程启动后修改器会自动连接，无需手动选择进程。
- 快速建造覆盖建筑、防御、步兵、车辆、舰船和飞机，并自动跟随当前玩家。
- 快速建造在下一次游戏生产更新推进到完成步骤，仍需足额资金；资金不足时等待。保留手动暂停、建筑放置、出厂动画与出口阻塞规则。
- 关闭快速建造停止加速后续生产，已推进的进度不回退；正常退出恢复补丁原指令并注销热键。
- 从旧版更换到 1.0.0 时，先关闭旧修改器并重启游戏，避免旧版工厂数量改写或补丁残留。
- 一键全图为一次性操作，每局需要重新按一次。
- 电力修复在游戏供电结算中生效，开关后等待游戏继续运行并完成一次供电重算；暂停游戏时不会立即更新。
- 发现“电力补丁指令不匹配”等错误时，保留诊断并关闭其他修改器；程序会拒绝覆盖未知指令。

验证电力修复时，先在遭遇战中建立真实缺电状态，确认开启后雷达、耗电防御建筑及生产速度恢复；再建造/出售发电设施，最后关闭功能，确认恢复实际电力限制。测试过程中的电力表满格本身不代表验证通过。建造修复需分别检查建筑、单位及连续队列，确认正常扣款、暂停有效、关闭后恢复常规生产。1.0.0 已通过正式 AI 遭遇战验收，并通过模拟进程、指令仿真及界面检查。

## 故障排查

点击界面中的“复制诊断”，将内容连同问题一起提交 Issue。诊断信息包含版本、系统、进程状态和运行记录，不包含任何个人凭据。

常见问题：

- “未检测到 gamemd.exe”：游戏未启动，或进程名被第三方启动器重命名。
- “请先进入一局游戏”：已连接游戏进程，但尚未进入对局。
- 功能不生效：确认游戏为 3.3.6 版本；其他版本布局不同，修改器会拒绝写入。
- 快捷键无响应：使用界面按钮代替；两者逻辑完全相同。

## 安全提示

- 仅用于单机游戏，不要用于联机对战。
- 1.0.0 的 exe 未签名，校验值见 Release 中的 SHA256SUMS.txt。
- 仅从本仓库 Release 下载并核对 SHA-256。
